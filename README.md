## 🤖 OpenClaw — My Local AI Agent

I'm building **OpenClaw**, a self-hosted AI agent running on an NVIDIA Jetson Orin Nano. It's wired into GitHub, Slack, and the rest of my stack — an always-on coding and ops agent that lives on my local hardware.
